# 제재와 심각도

심각도는 법정 제재의 종류로 정한다. GDPR식 등급을 그대로 가져오지 않는다.

| 심각도 | 기준 |
|---|---|
| 치명 | 형사처벌(징역·벌금) 조항 위반 가능성 |
| 높음 | 과태료 조항 위반 가능성 |
| 보통 | 법령 조항은 지켰으나 문서·코드가 서로 어긋나 분쟁·점검에서 지적될 수 있음, 또는 고시·지침 미흡 |
| 낮음 | 권고, 모범 사례, 사용성 |

## 위치정보법 주요 제재 (교육자료 기준 요약)

아래는 방송미디어통신위원회·KISA 2026년 사업자 대상 교육자료에 실린 조항별 제재다. 금액과 조문 번호는 개정될 수 있으므로 보고서에는 "현행 조문 확인 필요"를 붙이고, 확정이 필요하면 국가법령정보센터에서 위치정보법 제39조~제43조를 확인한다.

| 위반 | 제재 유형 | 교육자료상 조항 |
|---|---|---|
| 동의 없이 개인위치정보 수집·이용·제공 (제15조 제1항) | 징역 또는 벌금 (치명) | 제40조 등. 교육자료 안에서도 3년/3천만원과 5년/5천만원 두 기재가 있으므로 현행 조문 확인 |
| 타인 단말 복제·도용으로 위치정보 제공받음 (제15조 제2항) | 징역 또는 벌금 | 제40조 |
| 미등록 개인위치정보사업 | 징역 또는 벌금 | 제39조 |
| 미신고 위치기반서비스사업·사물위치정보사업 | 징역 또는 벌금 | 제40조. 현행 조문 확인 필요 |
| 확인자료 자동 기록·보존 미이행 (제16조 제2항) | 징역 또는 벌금 (치명) | 제41조 |
| 목적 달성 후 개인위치정보 미파기 (제23조 제1항) | 징역 또는 벌금 (치명) | 제40조의2 (교육자료 파기 절 기준). 현행 조문 확인 필요 |
| 휴·폐업 시 위치정보 미파기 | 징역 또는 벌금 | 제41조 |
| 이용약관 미공개, 변경내용 미공개 (제12조) | 과태료 | 제43조 |
| 개인위치정보 처리방침 미수립·미공개 (제21조의2) | 과태료 | 제43조 |
| 제3자 제공 고지·통보 미이행 (제19조 제2항~제4항) | 과태료 | 제43조 |
| 일시중지 요구 거절, 기술적 수단 미비 (제24조 제2항) | 과태료 | 제43조 |
| 파기에 필요한 조치 미이행 (제23조 제2항) | 과태료 | 제43조 |
| 동의 철회 시 개인위치정보·확인자료 미파기 (제24조 제4항) | 과태료 | 제43조 |
| 14세 미만 법정대리인 동의 미획득·미확인 | 과태료 | 제43조 |
| 위치추적 장치 부착 물건 판매·대여 시 미고지 (제15조 제3항) | 과태료 | 제43조 |

## 보고서 표기 규칙

- 금액을 쓰면 출처("교육자료 기준")와 "현행 조문 확인 필요"를 같이 쓴다.
- 금액보다 제재 유형(형사, 과태료)과 근거 조항을 우선한다.
- 겁주는 표현은 쓰지 않는다. 무엇을 고치면 되는지가 먼저다.
- 개인정보보호법 제재(과징금, 과태료)는 금액을 기억으로 쓰지 않는다. 조항만 적는다.
