# 위치기반서비스 이용약관 체크리스트

위치정보사업자와 위치기반서비스사업자는 모두 이용약관을 공개해야 한다 (법 제12조). 개인정보 처리방침과 별개의 문서다. 위치정보사업과 위치기반서비스사업 약관은 하나로 합칠 수 있지만, 이 경우 제18조와 제19조의 명시사항을 모두 넣어야 한다.

각 항목은 통과, 미흡, 누락, 해당없음 중 하나로 판정하고 근거(문서 인용, URL, 파일:줄)를 단다.

## A. 공개와 변경

| # | 점검 항목 | 근거 | 통과 기준 |
|---|---|---|---|
| T1 | 약관이 공개되어 있다 | 법 제12조 | 사업자 홈페이지, 또는 위치정보를 수집하는 단말의 첫 화면이나 그와 연결된 화면에서 누구나 볼 수 있다 |
| T2 | 앱 안에서 접근 경로가 있다 | 법 제12조 | 가입 동의 화면과 설정·약관 메뉴에서 열린다. 링크가 실제로 열리는지 확인 |
| T3 | 변경 이유와 변경 내용을 쉽게 확인할 수 있다 | 법 제12조 | 개정 시 변경 전후 비교, 글자 크기·색 등으로 눈에 띄게 표시. 시행일과 개정 이력 |
| T4 | 문서 버전이 하나로 관리된다 | 운영 권고 | 앱 내 웹뷰, 웹 사이트, 스토어 링크가 같은 버전을 가리킨다 |

## B. 위치기반서비스사업자 약관 필수 기재 (법 제19조 제1항, 시행령)

| # | 점검 항목 |
|---|---|
| T5 | 위치기반서비스사업자의 상호, 주소, 전화번호 그 밖의 연락처 |
| T6 | 개인위치정보주체와 법정대리인의 권리와 그 행사 방법 (법정대리인은 14세 미만 동의가 필요한 경우) |
| T7 | 제공하려는 위치기반서비스의 내용 (기능 단위로 구체적으로) |
| T8 | 위치정보 이용·제공사실 확인자료의 보유근거와 보유기간 |
| T9 | 개인위치정보의 보유목적과 보유기간 |
| T10 | 법 제19조 제3항에 따른 통보(제3자 제공 시 사후통보)에 관한 사항 |
| T11 | 서비스의 내용, 수집·이용·제공에 관한 요금과 조건 (무료면 무료라고 적는다) |

## C. 위치정보사업자 약관 필수 기재 (법 제18조 제1항, 해당 시)

OS 위치 API로 얻은 위치를 이용만 하는 앱이면 T12~T17은 "해당없음: 측위 주체는 OS·통신사"로 닫는다. 자체 측위 설비(비콘, Wi-Fi 신호 DB 등)로 위치를 만들어 다른 사업자에게 제공할 때만 점검한다.

| # | 점검 항목 |
|---|---|
| T12 | 위치정보사업자의 상호, 주소, 전화번호 그 밖의 연락처 |
| T13 | 개인위치정보주체와 법정대리인의 권리와 행사 방법 |
| T14 | 위치기반서비스사업자에게 제공하려는 서비스의 내용 |
| T15 | 위치정보 수집사실 확인자료의 보유근거와 보유기간 |
| T16 | 개인위치정보의 보유목적과 보유기간 |
| T17 | 개인위치정보의 수집방법 |

## D. 내용과 실제 동작의 일치 (가장 자주 깨지는 부분)

| # | 점검 항목 | 확인 방법 |
|---|---|---|
| T18 | 약관의 서비스 내용(T7)이 코드에서 위치를 쓰는 기능 전체를 덮는다 | `code-audit.md`의 위치 사용 지점 목록과 대조. 약관에 없는 기능이 위치를 쓰면 누락 |
| T19 | 약관의 정밀도 표현이 실제와 맞다 | "시·군·구 단위만 이용"이라 쓰고 정밀 좌표(FINE, 소수점 6자리)를 서버로 보내면 불일치 |
| T20 | 보유기간 표현이 실제 저장과 맞다 | "이용 후 즉시 파기"라 쓰고 DB·로그에 좌표가 남으면 불일치 |
| T21 | 확인자료 보유기간이 실제 로그 보존 설정과 맞다 | 약관에 6개월이라 쓰면 로그 보존 정책도 6개월 이상인지 |
| T22 | 제3자 제공 문구가 실제 수신자와 맞다 | 지도·지오코딩·날씨 API, 분석 SDK로 좌표가 나가는지 확인하고 약관·처리방침의 수신자·위탁 목록과 대조 |

## 판정 규칙

- 문서를 직접 읽지 못했으면(로그인 벽, 요약만 받은 경우) "누락"이 아니라 "확인 불가"로 적는다. 원문은 `curl -sL <url>`로 받아 텍스트를 추출하고, 요약 도구의 결과만으로 누락을 단정하지 않는다.
- 같은 내용이 처리방침에 있고 약관에 없으면 약관 항목은 "누락"이다. 법 제12조는 약관 자체의 공개를 요구한다.
- "등"으로 뭉뚱그려 기능이나 수신자를 특정하지 못하면 "미흡".
