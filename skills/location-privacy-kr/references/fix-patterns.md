# 수정 패턴

fix 모드에서 쓴다. 고치는 순서는 심각도 순(치명 → 높음 → 보통)이고, 같은 심각도 안에서는 코드가 먼저, 문서가 나중이다. 문서는 코드가 실제로 하는 일을 적어야 하기 때문이다.

모든 법률 문구 초안 맨 위에 다음 주석을 남긴다.

```text
<!-- 이 초안은 location-privacy-kr 스킬이 만든 점검 결과 기반 초안입니다. 시행 전 법률 검토가 필요합니다. 점검일: YYYY-MM-DD -->
```

`{{...}}`는 사용자가 채울 자리표시자다. 회사명, 책임자 이름, 연락처를 추측해서 채우지 않는다. 저장소나 기존 문서에 이미 공개된 값만 옮긴다.

## 코드

### F1. 위치 동의를 OS 권한 앞에, 서버에서도 집행

1. 위치 기능 진입 시 서버의 위치약관 동의 상태를 조회한다.
2. 미동의면 위치기반서비스 이용약관 전문 링크와 함께 동의 화면을 보여준다. OS 권한 팝업은 그 다음이다.
3. 좌표를 받는 서버 API는 동의 상태를 다시 확인하고, 미동의·철회·일시중지 상태면 좌표를 버리고 거절한다.

### F2. 철회와 일시중지

- 설정 화면에 "위치정보 이용 동의" 항목: 철회 버튼, 일시중지 토글(가능하면 기간 선택).
- 서버: 동의 상태를 `agreed | paused(until) | withdrawn` 같은 상태로 관리한다. `withdrawn` 전이 시 개인위치정보와 확인자료 파기 작업을 건다.
- OS 권한 해제와 동의 철회는 다른 것이다. 설정 화면에서 둘을 구분해 보여준다.

### F3. 확인자료 자동 기록

위치를 쓰는 서버 핸들러마다 공통 미들웨어나 데코레이터로 남긴다. 좌표는 넣지 않는다.

```sql
-- 예시 스키마. 이름과 타입은 프로젝트 관례에 맞춘다.
CREATE TABLE location_use_log (
  id            BIGSERIAL PRIMARY KEY,
  subject_id    TEXT        NOT NULL,  -- 개인위치정보주체 식별자
  source        TEXT        NOT NULL,  -- 취득경로: GPS, WIFI, CELL, BEACON
  handler       TEXT        NOT NULL,  -- 취급자(서비스 주체)
  service       TEXT        NOT NULL,  -- 제공 서비스(기능 이름)
  recipient     TEXT        NOT NULL,  -- 제공받는 자 (본인 이용이면 'self')
  used_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);
-- 보존: 최소 6개월. 삭제 배치는 6개월이 지난 행만 지운다.
```

열람·고지 처리 기록은 별도 테이블(처리자, 요청자, 목적, 일시)로 둔다.

### F4. 최소 수집

- 시·군·구 단위면 충분한 기능: Android `ACCESS_COARSE_LOCATION`, iOS 대략적 위치 허용, 서버 전송 전 좌표 반올림(소수점 2자리 ≈ 1km).
- 쓰지 않는 권한 선언 제거: 코드가 요청하지 않는 `NSLocationAlways*` 문구, 쓰지 않는 `ACCESS_BACKGROUND_LOCATION`, `ACCESS_MEDIA_LOCATION`.
- 화면 포커스마다 다시 보내는 호출은 캐시(예: 일정 거리·시간 안이면 재사용)로 줄인다.

### F5. 즉시 파기

- 결과만 필요하면 좌표를 저장하지 않는다. 요청 로그·에러 로그에서 좌표 필드를 마스킹한다.
- 저장이 필요하면 목적과 기간을 정해 TTL을 걸고 약관·처리방침에 같은 기간을 쓴다.
- 회원 탈퇴 시 서버의 위치 데이터 삭제 경로를 만든다.

### F6. 제3자 제공 사후통보

공유가 일어날 때마다 통보 이벤트를 만든다(받는 자, 일시, 목적). 이용자가 고른 방식에 따라 즉시 푸시·인앱 알림을 보내거나, 사전 동의를 받은 경우 30일 이내 주기로 모아서 보낸다.

### F7. 연령 분기

가입 시 생년월일 등으로 8세 이하 / 8세 초과 14세 미만 / 14세 이상을 가른다. 14세 미만이면 본인 동의 화면과 법정대리인 동의 화면을 따로 두고, 법정대리인 확인(휴대전화 본인인증 등) 결과를 저장한다. 14세 미만을 받지 않는 서비스면 가입을 막고, 약관의 14세 미만 조항과 모순되지 않게 정리한다.

## 문서

### D1. 위치기반서비스 이용약관 골격

### D2. 처리방침의 개인위치정보 절

`privacy-policy-checklist.md` 2층 L1-L7 순서대로 쓴다. 약관과 같은 값(보유기간, 책임자, 통보 방식)을 쓰고, 다르면 하나로 맞춘다.

### D3. 문서와 코드 맞추기

문서를 고치기 전에 위치 데이터 지도를 다시 본다. 문서에 쓰는 기능 목록, 정밀도, 보유기간, 수신자는 지도에 있는 값만 쓴다. 지도에 "확인 불가"인 값(서버 보존 기간 등)은 자리표시자로 두고 확인 요청 목록에 올린다.

## 하지 않는 것

- 문서를 배포하거나 웹 페이지(노션, CMS 등)를 직접 수정하지 않는다. 파일로 초안을 만들고 반영 위치를 안내한다.
- 등록·신고 서류를 대신 제출하지 않는다.
- 운영 DB의 데이터를 지우거나 바꾸지 않는다. 마이그레이션 파일과 배치 코드까지만 만든다.
