# 적용 대상 판정

점검의 첫 단계. 여기서 결론이 갈리면 이후 체크리스트 범위가 달라진다. 판정 결과는 보고서 맨 위에 근거와 함께 적는다.

## 1. 위치정보인가

법 제2조 제1호의 위치정보는 다음 세 가지를 모두 만족한다.

1. 이동성이 있는 물건 또는 개인(휴대전화, 차량, 웨어러블 등)에 관한 정보
2. 특정 시간에 존재하거나 존재했던 장소에 관한 정보 (과거와 현재 모두 포함)
3. 전기통신설비·전기통신회선설비로 측위한 정보 (GPS, Wi-Fi, 기지국, 비콘, NFC 등)

| 코드에서 보이는 것 | 판정 |
|---|---|
| OS 위치 API(GPS·네트워크 측위)로 얻은 좌표 | 위치정보 |
| Wi-Fi 스캔 결과, BLE 비콘 근접, 기지국(Cell-ID)으로 계산한 위치 | 위치정보 |
| 지오펜스 진입·이탈 이벤트 | 위치정보 (측위 결과에서 나온 장소 정보) |
| 사용자가 직접 입력한 주소(배송지, 회원가입 주소), 지도에서 직접 고른 지점 | 위치정보 아님 (측위 아님). 개인정보보호법만 적용 |
| 사진 EXIF GPS 태그를 읽어 사용 | 위치정보로 다룰 가능성이 높음. "판단 필요"로 표시 |
| IP 주소 기반 대략 위치 | 판단이 갈림. "판단 필요"로 표시하고 근거를 적는다 |

## 2. 개인위치정보인가

법 제2조 제2호. 특정 개인의 위치정보, 또는 위치정보만으로는 개인을 알 수 없어도 다른 정보와 쉽게 결합해 알 수 있는 경우를 포함한다.

- 로그인 사용자의 단말에서 측위해 계정 ID와 함께 서버로 보내면 개인위치정보다.
- 차량 위치(사물위치정보)라도 배차일지·운전자 정보와 쉽게 결합되면 개인위치정보다.
- 결합 가능성은 합법적으로 접근 가능한 정보 기준이다. 결합에 비합리적인 비용이나 노력이 들면 "쉽게 결합"으로 보지 않는다.

## 3. 사업자 유형

| 유형 | 정의 | 행정절차 |
|---|---|---|
| 개인위치정보사업자 | 측위설비로 개인위치정보를 수집해 위치기반서비스사업자에게 제공하는 사업 (이동통신사, OS 사업자 등) | 등록 (법 제5조) |
| 사물위치정보사업자 | 개인위치정보가 아닌 위치정보를 수집·제공하는 사업 | 신고 (법 제5조의2) |
| 개인위치기반서비스사업자 | 개인위치정보를 이용한 서비스 제공을 사업으로 하는 자. **일반 앱 사업자는 대부분 여기** | 신고 (법 제9조, 소상공인 등은 제9조의2 특례). 교육자료는 사업 개시 후 1개월 이내 신고를 안내하나, 사후 신고가 일반에 적용되는지 특례에 한정되는지는 현행 조문 확인 필요 |
| 사물위치기반서비스사업자 | 사물위치정보만 이용하는 서비스 | 신고 불필요 |

OS 위치 API로 좌표를 얻어 앱 기능에 쓰는 일반 앱은 측위 주체가 OS·통신사이고, 앱 사업자는 그 위치정보를 **이용**하는 위치기반서비스사업자에 해당하는 경우가 많다.

### 신고 대상 여부를 가르는 신호

| 신호 | 판단 방향 |
|---|---|
| 좌표나 위치 파생값을 사업자 서버로 보내 DB·지도 등과 가공해 결과를 돌려준다 | 신고 대상 쪽. 서버에 저장하지 않고 바로 지워도 마찬가지다 |
| 좌표가 단말 밖으로 나가지 않고 단말 안에서만 처리된다 | 비신고 쪽. 단, 자동삭제 소스코드 등 증빙을 갖춰야 한다 |
| 회사 내부 근로감독·보안구역 관리에만 쓴다 | 위치정보사업·위치기반서비스사업에 해당하지 않는다 (사업으로 영위하지 않음) |
| 위치를 사용자가 지정한 제3자에게 보여준다 (친구 찾기, 가족 위치, 안심 알림) | 신고 대상. 제3자 제공 동의와 사후통보 의무도 붙는다 |
| 사용자가 직접 운영하는 서버로만 보낸다 (셀프호스팅 오픈소스) | 앱 배포자가 처리하지 않는 구조일 수 있다. "운영자 없음/판단 필요"로 표시하고, 배포자가 운영하는 기본 서버가 있는지 따로 확인한다 |
| 위치추적 장치가 붙은 물건을 판매·대여한다 | 법 제15조 제3항 고지의무. 판매 문구가 동의 없는 추적을 부추기지 않는지 확인 |

최종 판정이 애매하면 "판단 필요"로 남기고 위치정보지원센터 상담을 권고한다. 스킬이 신고 여부를 확정하지 않는다.

## 4. 개인정보보호법과의 관계

개인위치정보에는 특별법인 위치정보법이 우선 적용되지만, 개인정보보호법상 의무(처리방침, 안전조치, 권리 보장 등)도 같이 확인한다. 흔히 놓치는 것:

- 개인정보 수집 동의만 받고 위치정보 동의를 따로 받지 않음
- 개인정보 처리방침만 공개하고 위치기반서비스 이용약관 자체를 공개하지 않음 (법 제12조)
- 일반 안전조치는 했으나 확인자료 자동 기록·보존 장치가 없음 (법 제16조 제2항, 형사처벌)
- 제3자 제공 동의는 받았으나 즉시 사후통보나 모아서 통보받는 절차가 없음 (법 제19조 제3항·제4항)
- 동의 철회는 처리하면서 즉시 파기를 빠뜨림 (법 제24조 제4항)

## 5. 판정 결과 표기

보고서 첫머리에 다음 형식으로 적는다.

```text
적용 판정
- 위치정보 처리: 있음 (GPS 좌표, src/location/useLocation.ts:42)
- 개인위치정보: 해당 (로그인 계정과 함께 서버 전송, api/nearby.ts:18)
- 사업자 유형(추정): 개인위치기반서비스사업자 → 신고 필요 여부 확인 필요
- 제3자 제공: 없음 / 있음(친구 공유)
- 14세 미만 이용 가능성: 가입 연령 제한 없음 → 해당 가능
- 근거가 부족한 판단: IP 기반 지역 추정(analytics) — 판단 필요
```
