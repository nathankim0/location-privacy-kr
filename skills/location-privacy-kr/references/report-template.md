# 보고서 형식

보고서는 두 층이다. 위는 결정하는 사람이 5분 안에 읽는 요약, 아래는 고치는 사람이 쓰는 상세. 빈 표를 채우려고 칸을 만들지 않는다. 해당 없는 절은 한 줄로 "해당없음: 이유"만 쓴다.

저장 위치: 대상이 사용자의 작업 저장소면 `docs/compliance/location-privacy-YYYY-MM-DD.md`, 남의 저장소나 읽기 전용 대상이면 저장소 밖(임시 폴더나 현재 디렉터리). 사용자가 저장하지 말라고 하면 대화에만 출력한다.

- 문서: {{약관 URL/파일}}, {{처리방침 URL/파일}}
- 점검일: YYYY-MM-DD / 기준: 위치정보법, 개인정보보호법 (현행 조문 확인 권장)

## 쓰는 규칙

- 발견사항 하나에 증거 하나 이상. 증거는 파일:줄, 문서 원문 인용(따옴표), URL 중 하나다. 증거 없는 문장은 발견사항이 아니다.
- 통과도 근거를 단다. "통과(약관 제6조: '6개월간 보관')".
- 확인하지 않은 항목을 통과로 쓰지 않는다. "확인 불가"는 실패가 아니라 별도 범주이고, 체크리스트 항목 단위로 센다.
- 조건부 발견사항은 전제를 한 줄로 적는다. 전제가 거짓으로 확정되면 그 발견사항은 해당없음으로 닫는다.
- 심각도가 "현행 조문 확인 필요" 표시된 제재 분류에 기대고 있으면 발견사항에도 그 표시를 옮긴다.
- 신고·등록 필요 여부, 위치정보 해당 여부처럼 법적 판단이 필요한 것은 "판단 필요"로 쓰고 판단 근거를 같이 적는다.
- 회사 내부 사정(인원, 조직)을 추측하지 않는다.
